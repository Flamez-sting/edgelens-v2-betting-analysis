# EdgeLens Free V2

A no-cost front-end upgrade for EdgeLens.

Included:
- Edge Scanner with search, sport filter and minimum-edge filter
- Best-odds comparison
- Implied probability and estimated fair probability
- Edge calculation
- Line-movement dashboard
- Arbitrage calculation interface
- Stake/exposure calculator
- Persistent watchlist using localStorage
- Basic alert indicator
- Responsive mobile UI
- No paid API required for the demo build

Important: the included prices are demonstration data. Genuine live bookmaker odds require a lawful data source/API and should be connected separately.
